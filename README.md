# Графический калькулятор

Учебная модель школьного графического калькулятора — для учеников, которым такой калькулятор нужен по программе (Cambridge IGCSE International Mathematics 0607 и похожие). Раскладка клавиш, меню и порядок нажатий повторяют Casio fx-CG50, чтобы навык переносился на настоящий прибор. Интерфейс на английском, как у оригинала.

Адрес: `https://maksimmartynov2000-spec.github.io/graficheskiy-kulkulyator/`

Это не эмулятор и не продукт Casio: прошивка, логотипы и рисунки оригинала не используются, значки и шрифт свои. На экзамен нужен настоящий калькулятор — приложение для тренировки.

## Что умеет

| Режим | Что есть |
|---|---|
| Run-Matrix | Естественный ввод (дроби, корни, степени), точные ответы дробью и с √ и π, S⇔D, Ans, переменные A–Z, история с правкой и пересчётом, списки, матрицы, комплексные числа, меню OPTN и VARS, каталог команд, UNDO, CLIP и PASTE |
| Statistics | Списки, 1-VAR и 2-VAR, регрессии, диаграммы (Scatter, xyLine, Hist, MedBox, Bar, Broken, NPPlot, Pie, N-Dist), распределения, тесты (TEST) и доверительные интервалы (INTR) |
| Graph | Y=, r=, параметрические, X=, неравенства; Trace, Zoom, V-Window (с памятью V-MEM), G-Solv (ROOT, MAX, MIN, Y-ICEPT, INTSECT, Y-CAL, X-CAL, ∫dx), Sketch, MODIFY |
| Dyna Graph | График с меняющимся коэффициентом: встроенные формулы, показ с таймером и по шагам |
| Table | Таблица значений по Start/End/Step, правка X, столбец производной, график по точкам |
| Recursion | Последовательности aₙ, aₙ₊₁, aₙ₊₂: таблица, суммы, графики, паутинная диаграмма |
| Conic Graphs | Девять видов уравнений: параболы, окружность, эллипс, гиперболы; Trace и G-Solv (фокус, вершина, директриса, асимптоты…) |
| Equation | Системы линейных уравнений (2–6 неизвестных), многочлены (степень 2–6), Solver |
| Financial | Простые и сложные проценты, денежные потоки, амортизация, преобразование ставок, наценка, даты, износ, облигации |
| Memory | Что лежит в памяти и удаление по частям |
| System | Версия, сброс настроек и памяти |

Режимы, которых нет (eActivity, Spreadsheet, Program, E-CON4, Link, Python), показаны в главном меню серым — на своих местах, чтобы расположение совпадало с настоящим калькулятором.

## Как поставить на телефон или планшет

- **Android (Chrome):** открыть адрес → меню «⋮» → «Добавить на главный экран» (или «Установить приложение»).
- **iPhone, iPad (Safari):** открыть адрес → «Поделиться» → «На экран „Домой“».

После первого открытия калькулятор работает без интернета. Новые версии приходят сами: при открытии приложение проверяет, не вышла ли свежая сборка. Всё, что введено (история, функции, списки, настройки), хранится только на устройстве.

Кнопка «⋯» в правом верхнем углу корпуса — настройки самого приложения: тема (светлая, тёмная, как в системе), вибрация клавиш, версия и проверка обновления.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | Всё приложение одним файлом. **Собирается** из `src/` — руками не править. В начале — метка версии `<meta name="app-build">`. |
| `src/page.html`, `src/style.css`, `src/js/*.js` | Исходники: каркас страницы, стили, скрипт по модулям (список — в `CLAUDE.md`). |
| `sw.js`, `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | Работа без интернета, установка на экран «Домой», значки. |
| `tools/build.py` | Собирает `index.html` из исходников. |
| `tools/stamp.py` | Ставит метку версии: дата и короткий хэш содержимого. Если файл не менялся, метка остаётся прежней. |
| `tools/check.js` | Проверка вида на 10 размерах экрана, нажатий, сохранения состояния, самообновления и работы без сети. Скриншоты — в `.work/`. |
| `tools/icons.js` | Рисует значки приложения. |
| `tests/` | Тесты: `engine.js` (ядро вычислений), по файлу на режим (`stat.js`, `eqn.js`, `recur.js`, `conic.js`, `dyna.js`, `fin.js`…), `ui.js` (сценарии «с клавиш» в браузере), `monkey.js` (случайные нажатия); `all.js` — всё подряд; `shot.js` — снимок любого экрана. |
| `CLAUDE.md` | Правила для Claude и принятые решения. |
| `.nojekyll` | Чтобы GitHub Pages отдавал файлы как есть. |

Порядок перед коммитом: `python3 tools/build.py` → `python3 tools/stamp.py` → `node tests/all.js` → `node tools/check.js`.

## Как работает самообновление

1. `tools/stamp.py` записывает в начало `index.html` метку вида `2026-11-25·e748e3a8`.
2. Приложение при открытии, при возврате на экран и раз в 10 минут скачивает первые 4 КБ свежего `index.html` (с меткой времени в адресе, чтобы обойти кэш) и сравнивает метки.
3. Метка другая → если калькулятором сейчас не пользуются, страница перезагружается; иначе — плашка «Update». Состояние сохраняется после каждого нажатия, так что обновление ничего не теряет.
4. Защита от петли: если за 10 минут дважды не удалось перейти на новую версию, остаётся только плашка.

GitHub Pages обновляет сайт через 1–2 минуты после мержа, а кэширует страницы до 10 минут — поэтому новая версия на устройствах появляется в пределах нескольких минут.
